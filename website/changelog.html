What's new in Axo Client

Every release and what changed. Newest first.

v0.1.0

First release Minecraft 1.21.11
  • First public build of the Axo Client Fabric mod for Minecraft 1.21.11.
  • HUD modules: FPS, coordinates, CPS counter, keystrokes, memory, ping, speed, health, hunger, XP, facing direction, a real-time clock, day counter, session uptime, and a module list.
  • QoL modules: fullbright and hold-to-zoom; movable HUD with nine anchor points and an in-game layout editor.
  • Cosmetics: four built-in capes plus a dozen particle trails and auras — all rendered locally.
  • In-game ClickGUI (Right Shift) with themes, accent colors, live search, custom keybinds, and toast notifications.
  • Bundled Sodium and Lithium, version-matched and installed automatically.
  • Redesigned launcher: 3D character render, one-press LAUNCH, version picker, and a news panel.
  • Launcher accounts: multiple Microsoft accounts with one-click switching, plus a built-in skin changer.
  • Windows launcher core: automatic Java, hash-verified installs, repair, and self-update.

Next up

Planned
  • Rebindable keybinds and a full keybind editor.
  • Multi-version support with per-version install management.
  • Standalone portable and installer builds.
  • Code-signed installer to remove the SmartScreen warning.
