System requirements

Minimum

Windows 10 (64-bit) · 4 GB RAM · a Microsoft account that owns Minecraft: Java Edition · an internet connection for the first install.

Recommended

Windows 11 · 8 GB RAM · a dedicated GPU for the highest frame rates with Sodium. Java is installed automatically — you don't need it beforehand.
