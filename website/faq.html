Frequently asked questions

Everything you might want to know before you download.

Yes. Axo Client is completely free. You only need to own Minecraft: Java Edition, since you sign in with your own Microsoft account.
Axo is built to stay on the fair-play side of the line — it only shows information and rendering conveniences (like a CPS counter, zoom, and performance mods). It does not include reach, aim assistance, auto-clickers, or anything that gives an unfair advantage. That said, always follow the rules of the servers you play on.
No. The launcher automatically downloads the correct Java runtime, installs Fabric, and adds the bundled mods — all verified by hash. You just sign in and press Play.
Axo currently supports Minecraft 1.21.11. The whole system is designed to be data-driven, so more versions are added by publishing a manifest entry — multi-version management is on the roadmap.
The installer is not code-signed yet, so Windows SmartScreen shows a caution on first run. Click "More info → Run anyway". A signed installer is planned to remove this entirely.
Not yet — Axo is Windows-first. macOS and Linux builds are planned, and the client mod itself already runs anywhere Fabric does.
By default into an isolated folder in your app data (it never touches your vanilla .minecraft). You can change the install location during first-run setup or later in Settings.
Open Settings → Repair installation to re-verify and restore any missing or corrupted files, or Settings → Open log folder to see what happened. You can also report issues on GitHub.
