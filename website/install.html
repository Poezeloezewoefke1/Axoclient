Installation guide

From download to playing

The whole thing takes a few minutes. You do not need to install Java or any mods yourself.

Download the installer

Head to the download page and get the Windows installer (an .exe).

Run it

Double-click the installer. If Windows SmartScreen appears, choose More info → Run anyway — this happens because the app isn't code-signed yet, not because anything is wrong.

Complete first-run setup

On first launch Axo asks how much memory to give Minecraft and confirms the install location. Sensible defaults are pre-filled — you can change these later in Settings.

Sign in with Microsoft

Click Sign in with Microsoft and log in with the account that owns Minecraft: Java Edition. Your session is encrypted on your device and stays signed in.

Press Play

Pick your version and hit Play. Axo downloads the right Java runtime, installs Fabric and the mods, verifies every file, and launches the game with Axo running. The first launch is the slowest; after that it's instant.

Tune it in-game

Press Right Shift in-game to open the Axo menu. Toggle modules, and open the HUD editor to move things exactly where you want them.

Something went wrong? Open Settings → Open log folder to see what happened, or use Settings → Repair installation to re-verify and restore any missing files. Still stuck? Open an issue on GitHub.
